Definition of Terms

Group 6
The student group creating this portfolio site; contains individual member pages linked from this index.
Portfolio
A personal page for each member (e.g., Aristotle) showcasing skills, projects, and contact details.
Member
An individual listed on this site who contributed to the Group 6 project and maintains a personal portfolio page.
Project
Work or assignment described on a member's portfolio, such as class projects or practice apps.
Weather Widget
The small panel on this page that fetches current weather data from the Open‑Meteo API and displays it to visitors.
API
Application Programming Interface — this site uses external APIs (for example, Open‑Meteo for weather) to fetch dynamic data.
Dark Mode
A theme option available on some portfolio pages that inverts the color scheme; the preference is stored in the browser using localStorage.
